# 🥗 GiziMeal - Full-Stack Web Application

**GiziMeal** adalah platform kesehatan dan nutrisi berbasis web yang dirancang untuk membantu pengguna mengklasifikasikan bahan makanan secara otomatis menggunakan kecerdasan buatan (AI Image Recognition), menghitung Angka Kecukupan Gizi (AKG) personal, serta mencari resep makanan bergizi tinggi yang dipersonalisasi.

---

## 🚀 Fitur Utama

1. **AI Image Recognition (Deteksi Bahan Makanan)**
   * Mengunggah gambar bahan makanan (single atau multi-images).
   * Klasifikasi otomatis jenis bahan makanan menggunakan **Model AI GiziMeal** yang sudah dilatih.
   * Rekomendasi resep dan analisis nutrisi instan berdasarkan bahan makanan yang dideteksi.
       
2. **Kalkulator AKG & Gizi Harian**
   * Menghitung nilai **BMR (Basal Metabolic Rate)** dan **TDEE (Total Daily Energy Expenditure)** berdasarkan profil fisik (Jenis Kelamin, Usia, Berat Badan, Tinggi Badan) dan tingkat aktivitas.
   * Memberikan target makronutrisi harian (Karbohidrat, Protein, Lemak) yang disesuaikan dengan target kesehatan pengguna (Maintain, Weight Loss, Weight Gain).

3. **Tabel Database Gizi**
   * Menampilkan basis data nutrisi makanan sesuai dnegan dataset yang sudah di bersihkan.
   * Dilengkapi fitur pencarian, filter, pengurutan (kalori terendah/tertinggi, protein tinggi, serat tinggi), serta visualisasi skor AKG.

4. **Riwayat Resep AI (Persistensi Data)**
   * Menyimpan semua riwayat deteksi bahan makanan serta resep masakan rekomendasi AI langsung ke database cloud **Supabase**.
   * Memungkinkan pengguna untuk melihat kembali detail resep sebelumnya dari halaman profil tanpa perlu generate ulang (menghemat kuota API).

5. **Manajemen Akun & Autentikasi**
   * Sistem registrasi, login, ganti password, edit nama profil, hingga hapus akun secara aman menggunakan **Supabase Auth**.

## 🛠️ Tech Stack

### Frontend
* **Core**: React.js (Vite), JavaScript (ES Modules)
* **Styling**: TailwindCSS & Vanilla CSS
* **Routing**: React Router DOM (v7)
* **Library**: SweetAlert2 (untuk notifikasi premium)

### Backend
* **Runtime & Framework**: Node.js & Express.js
* **Database Client**: Supabase JS SDK
* **AI Engine**: Model AI GiziMeal
* **Tools**: Nodemon, Multer, Axios

## 🗄️ Konfigurasi Database Supabase

Untuk menjalankan aplikasi ini dengan lancar, pastikan tabel-tabel berikut sudah terbuat di database Supabase Anda:

### 1. Tabel `user_profiles`
Menyimpan data fisik pengguna untuk kalkulator AKG.
```sql
create table user_profiles (
  id uuid references auth.users on delete cascade primary key,
  gender text check (gender in ('laki-laki', 'perempuan')),
  usia integer,
  berat_badan float,
  tinggi_badan float,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);
```

### 2. Tabel `kalkulator_results`
Menyimpan target gizi harian hasil perhitungan kalkulator.
```sql
create table kalkulator_results (
  user_id uuid references auth.users on delete cascade primary key,
  bmr float,
  tdee float,
  target float,
  karbo integer,
  protein integer,
  lemak integer,
  goal_label text,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);
```

### 3. Tabel `scan_history`
Menyimpan riwayat deteksi bahan makanan lewat gambar.
```sql
create table scan_history (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users on delete cascade,
  bahan text,
  skor integer,
  created_at timestamp with time zone default timezone('utc'::text, now())
);
```

### 4. Tabel `recipe_history`
Menyimpan riwayat resep makanan rekomendasi Gemini AI.
```sql
create table recipe_history (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users on delete cascade,
  menu_name text,
  recipe_data jsonb,
  created_at timestamp with time zone default timezone('utc'::text, now())
);
```

## ⚙️ Variabel Lingkungan (Environment Variables)

### Backend (`/backend/.env`)
Buat file bernama `.env` di dalam folder `backend/` dan isi dengan konfigurasi berikut:
```env
PORT=3000
HOST=localhost

# Konfigurasi Supabase
SUPABASE_URL=https://your-supabase-project.supabase.co
SUPABASE_SERVICE_KEY=your-supabase-service-role-key

# API Keys pihak ketiga
GEMINI_API_KEY=your-gemini-api-key
PEXELS_API_KEY=your-pexels-api-key
```

### Frontend (`/frontend/.env`)
Opsional, tambahkan konfigurasi jika diperlukan untuk mendefinisikan port atau server API URL. File ini sudah otomatis dimasukkan ke `.gitignore` frontend demi keamanan.

## 🏃‍♂️ Cara Menjalankan Aplikasi Secara Lokal

Pastikan Anda telah menginstal [Node.js](https://nodejs.org/) di komputer Anda.

### Langkah 1: Instalasi Dependensi
Jalankan perintah ini di root folder untuk menginstal library backend dan frontend:

**Backend:**
```bash
cd backend
npm install
```

**Frontend:**
```bash
cd ../frontend
npm install
```

### Langkah 2: Jalankan Server Development

**Jalankan Backend (pada port 3000):**
```bash
cd backend
npm run start:dev
```

**Jalankan Frontend (pada port default Vite, 5173):**
```bash
cd frontend
npm run dev
```

Buka browser Anda dan akses `http://localhost:5173`. Aplikasi GiziMeal siap digunakan!
